# Installation & Environment Setup For Node JS

#### Things To Install
1. NodeJS
2. NPM
3. Visual Studio Code
4. Postman

## Install Node JS & NPM
###### NODE JS: Node.js is an open-source and cross-platform JavaScript runtime environment.

###### NPM: `npm` is a package manager for Node.js with hundreds of thousands of packages.

• Download Node JS from `https://nodejs.org/en`. Then install.

• `npm` will be automatically installed after Node JS installation.

#### To Check Node JS Version
```
node -v
```

#### To Check npm Version
```
npm -v
```

## Install VS Code

• Download & Install Visual Studio Code from `https://code.visualstudio.com/download`.

## Install Postman

• Postman is a global software company that offers an API platform for developers to design, build, test, and collaborate on APIs.

• Download & Install Postman from `https://www.postman.com/downloads/`.
