# Create First Program In Node JS

#### Four Ways To Run JS

1. Online Compiler
2. Terminal
3. Web Browser
4. Visual Studio Code

• We will use VS Code.

• Open VS Code and create a new folder, and now you can create and place your JS files inside this folder.

• Create a new file named as `main.js`.

## main.js
```
let a = 20;
let b = 50;
let sum = a + b;
console.log(sum);
```

• Click on Terminal and select `New Terminal`.

• Write command: `node main.js` to execute JS file.
